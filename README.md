# MasedWorld Helper — мод-помощник модератора (Fabric, Minecraft 1.21.11)

Клиентский мод: ставится только модератору, на сервер ничего ставить не надо.

## Возможности
- **Круговое меню (R)**: Наказать ▸ (все правила 6.1–7.8), «⚡ последнее нарушение», Телепорт, История, Предупреждение, Размут, Кик, Ещё ▸ (Разбан, Ваниш, Инвентарь, Эндерсундук, Наблюдать, перезагрузка конфига), Цель ▸ (последние 8 писавших в чат), переключатель режима.
  ЛКМ — выбрать, ПКМ — назад, 1–9 — быстрый выбор, поле внизу — ник цели. Если смотришь прицелом на игрока, он сам становится целью.
- **Автодетект нарушений в чате** по правилам 6.1, 6.2, 6.3, 7.1–7.8 (оскорбления с обходом «дyрaк»/«идиоооот», угрозы, родные, флуд 3+ одинаковых, спам, фейк-ЛС/наказания, попрошайничество, ссылки/YouTube, IP и домены чужих серверов, призывы уйти/бунт, «не донатьте»/«сервер говно», «я админ»).
- **Режимы** (`/mh mode`):
  - `suggest` (по умолчанию) — в чате появляется строка с нарушением и кнопкой **[НАКАЗАТЬ]** (вставляет готовую команду, Enter) или клавиша **Y** — наказать сразу;
  - `auto` — мод сам выполняет `/mute`/`/ban` с паузой между командами и кулдауном на игрока;
  - `off` — слежение выключено, меню работает.
- Напоминание «снять донат» для 7.5 и 7.6, звуковой сигнал, журнал всех срабатываний в `config/masedhelper/log.txt`.

## Команды
`/mh` — справка · `/mh punish <ник> <правило>` · `/mh ignore <ник>` · `/mh staff <ник>` (ник персонала — для 6.2) · `/mh test <текст>` — проверить фразу · `/mh apply` · `/mh reload`

## Наказания по умолчанию
| Правило | Команда |
|---|---|
| 6.1 | `/mute ник 3h 6.1` |
| 6.2 | `/ban ник 5h 6.2` |
| 6.3 | `/ban ник 2d 6.3` |
| 7.1 | `/mute ник 30m 7.1` |
| 7.2 | `/mute ник 1h 7.2` |
| 7.3 | `/mute ник 30m 7.3` |
| 7.4 | `/banip ник 2d 7.4` |
| 7.5 | `/banip ник 7.5` (навсегда) + снять донат |
| 7.6 | `/ban ник 7.6` (навсегда) + снять донат |
| 7.7 | `/ban ник 7.7` (навсегда) |
| 7.8 | `/ban ник 1d 7.8` |

Если на MasedWorld синтаксис другой (например `/tempban`, `/tempmute` или срок указывается иначе) — поправь `muteCommand`, `banCommand`, `banIpCommand` и сроки в `config/masedhelper/config.json` (создаётся при первом запуске), затем `/mh reload`. Там же: списки слов, ники персонала, официальные домены, кнопки меню и `chatRegex` — формат строки чата сервера.

## Сборка .jar
**Вариант 1 — без программ (GitHub):** создай репозиторий, загрузи туда содержимое этой папки (вместе с `.github`). Во вкладке **Actions** запустится сборка (подтягивает свежие Fabric Loader/API), готовый `masedhelper-*.jar` скачай из артефакта сборки.

**Вариант 2 — на ПК:** установи JDK 21 и Gradle, в папке проекта `gradle build`, jar появится в `build/libs/`.

Установка: jar + Fabric API в папку `mods`, Fabric Loader для 1.21.11.
