MasedWorld Helper — Fabric 1.21.11

В проект включены исходники из архива и Punisher.java.
Целевая версия: Minecraft 1.21.11, Fabric, Java 21.

Сборка:
1. Установите JDK 21 и Gradle 9.2.1 или совместимую версию.
2. Откройте эту папку как Gradle-проект в IntelliJ IDEA либо выполните в терминале:
   gradle build
3. После успешной сборки JAR будет в папке build/libs/.
4. Установите Fabric Loader для Minecraft 1.21.11 и Fabric API 0.141.6+1.21.11.
5. Скопируйте MasedHelper-1.21.11-Fabric-1.0.0.jar в .minecraft/mods.

Управление из исходников:
R — круговое меню
Y — применить последнее найденное нарушение
Команды: /mh, /mh reload, /mh mode off|suggest|auto

ВАЖНО:
Этот архив — проект для сборки, а не готовый игровой JAR. Сборку в этой среде выполнить
не удалось: здесь нет Gradle и нет доступа к Maven/Gradle-репозиториям для загрузки
Minecraft/Fabric зависимостей. Не переименовывайте этот ZIP в .jar — это не сделает его модом.
Перед включением AUTO проверьте настройки команд в config/masedhelper/config.json:
мод отправляет настроенные команды на сервер от имени вашего игрового аккаунта.
